# Mini Mario Run

A small browser game inspired by classic side-scrolling platformers.

## Run it locally

From this folder, start a local web server:

```bash
cd /home/thelonelyzebra/Documentos/mario_game
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Controls

- Left / Right: move
- Up / Space: jump
- Restart: button on the page

## Objective

Collect coins, avoid enemies, and reach the flag before time runs out.
